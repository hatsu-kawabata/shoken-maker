# 商圏メーカー

**▶ https://shoken-maker.vercel.app/**

地図をクリックして円を描くと、円内の**人口・世帯数・年齢構成・人口ピラミッド**がその場で出る無料の商圏分析ツール。登録不要・全国対応。出店検討・チラシ配布圏・営業テリトリーの初期スクリーニングに。

- 人口・世帯数・男女比・平均年齢（円内の人口加重平均）
- 年齢3区分＋**人口ピラミッド（5歳階級×男女）**
- 住所検索でどこへでもジャンプ（地理院 AddressSearch API）
- URLに状態が入るのでそのままシェア可能（`?lat=..&lng=..&r=..`）
- 完全静的サイト。サーバ計算ゼロ、外部送信は地図タイルと住所検索のみ

## 使い方（ローカル）

```bash
python3 -m http.server 8137 -d web
# → http://localhost:8137 を開き、地図をクリック。半径スライダで300m〜5km
```

## データパイプライン

2020年国勢調査の500mメッシュ統計（e-Stat 統計GIS）を1次メッシュ単位で前集計した静的JSONを、
円が掛かった分だけ遅延ロードします（全国150メッシュ・計65MB、1操作で読むのは数MB）。

```bash
python3 scripts/fetch_mesh.py --sweep               # 総数・世帯(T001141)を全国分取得
STATS_ID=T001173 python3 scripts/fetch_mesh.py 5339 # 5歳階級×男女(T001173)を同コードで取得
python3 scripts/build_data.py                       # 両zipをマージ → web/data/{1次メッシュ}.json
node scripts/test_mesh.mjs                          # 座標計算・集計の検証(17本)
```

全国合計は国勢調査確定値（126,146,099人）と差883人（0.0007%）まで一致することをテストで確認しています。

## 精度の注意

- **常住（夜間）人口**です。昼間人口ではありません
- 2020年国勢調査は都心部で**年齢不詳率が高い**（例: 新宿駅1km圏で約15%）。ピラミッドの合計は
  総人口に一致せず、差分をUIに注記表示します
- 秘匿セル（人口僅少）は年齢内訳が合算先メッシュに計上されるため、円境界付近で僅かな誤差があります
- 円内判定はセルを2×2サブ点で近似した重み付き按分です
